
# 🏥 Reducing Avoidable Hospital Readmissions with Machine Learning
> **Which patients should discharge nurses call first?**  
> This repository builds, validates, and explains a Python classification model trained on 3,000 hospital admissions to flag patients at high risk of returning within 30 days—prioritising clinical transparency, honest validation, and recall over black-box accuracy.
### An interpretable, leak-free machine learning pipeline to identify high-risk patients at discharge and guide targeted post-hospital follow-up care.
